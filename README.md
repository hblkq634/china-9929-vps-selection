## 9929 是什么，为什么晚高峰更稳

AS9929 是联通骨干网里定位较高的一层，承载跨省、跨地市流量，业内常叫“联通精品网”或“联通优质线路”。它和负责国际方向的 AS10099 经常搭配出现，商家宣传的“9929+10099”就是这个组合。相比 AS4837，9929 的负载通常更低、拥塞更少，跨省访问海外或回程时跳数更短，高峰期表现更稳。

三网用户走 9929 优化产品时，回程路径大致是这样：

| 你的宽带 | 回程路径（以三网优化的 9929 产品为例） |
| --- | --- |
| 电信 | 联通 9929 → 电信 163 |
| 联通 | 直连 9929 |
| 移动 | 联通 9929 → 移动 CMI |

三方线路的定位差别可以这样记：**9929 是联通方向的优质骨干，4837 是更常见的普通骨干，CN2 GIA 是电信方向的高端线路**。9929 比 4837 质量高一档、价格也贵一点；和 CN2 GIA 比，9929 便宜，但电信回程的极致程度不如 GIA。所谓“联通 A 网”到底指 9929 还是 4837，公开资料里两种说法都有，选购时不必纠结这个称呼，看实际回程路由更可靠。

## 9929 的六个限制，哪些人别买

**出口资源有限。** 9929 不是自带完整国际出口的线路，很多“9929 优化”实际是“国内段走 9929 + 再接国际链路”，国际出口可能成为瓶颈。商家只讲回程走 9929，不讲出口接的是哪条链路，这种情况很常见。

**互联点少，覆盖有限。** 9929 的互联点和交换点比普通主干网少，部分省份或偏远地市接入体验不理想。你在广东测着很好，换到西北某省可能就不是一回事。

**非联通用户前端先吃亏。** 电信或移动宽带用户，从家宽到骨干网这一段可能先走普通联通或 AS4837，9929 的优化空间被压缩。商家说“三网可用”不等于“三网都优化”。

**端口和带宽常被限制。** 控成本的做法是压低端口带宽，标称 9929 但只给 20Mbps、50Mbps 的产品不少。大文件下载、高并发流媒体这类场景，先看带宽数字，再看线路标签。

**路由会变。** 路由是动态的，运营商调整或互联策略变化都可能让节点退回 AS4837。有测评提到少数节点在某个时段回程丢包、延迟抖动，就是线路切走了。

**目标用户在欧美时没意义。** 9929 优化的是中国大陆访问体验。你的用户主要在欧美，这条线的溢价就白花了，优先看海外本地线路。

替代方向按需求分：电信依赖极重、要最稳回程，看 CN2 GIA；要大带宽、不限流量、对峰值延迟不敏感，看 4837；要低延迟，看香港方向。DMIT 的 Pro 系列属于第一类，EB 系列适合移动用户和大流量场景，都比硬追 9929 标签更实际。

## 怎么验证一条 9929 线路是不是真的

买之前要测例，买之后自己测。工具用 `traceroute`（Linux）或 `tracert`（Windows），也可以让商家提供 LookingGlass 或路由探测页面。

看三个维度：

1. **回程，不是去程。** 从 VPS 往国内 IP 做 traceroute，看路径里是否出现 AS9929 或 AS10099。去程直连说明不了问题，回程才决定你下载、看视频、传文件时的体验。
2. **晚高峰测。** 晚上 20:00 到 23:00 之间测，这个时段普通骨干最容易拥塞，9929 的价值也在这时候体现。白天测出来漂亮，参考意义有限。
3. **三网分开测、跨省测。** 电信、联通、移动各找一个不同省份的测试点，看回程是否始终走 9929。商家写“三网回程 9929”，就要求它给对应测例。

带宽要看清楚是峰值带宽、实测带宽还是保障带宽，流量是计量还是限速，超流量是封顶还是降速。这些写在下单页角落里的条款，比线路标签更影响日常使用。
